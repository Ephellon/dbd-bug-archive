# 2.5.4 | Hotfix

## Lunar Event Changes

Adjusted the spawn rate of Red Envelopes in a level 50 Bloodweb to always have 2.

Adjusted the Killer Objectives:

- +3 Points for hooking a Survivor (up from +2)
- +4 Points for destroying a Lunar Vessel after hooking a Survivor (up from +3)

## Bug Fixes

- Fixed an issue that caused clients to receive Lunar event progress when the host quit the match during the transition into the match.
- Fixed an issue that caused the Wake Up! perk not to show exit gate auras.
